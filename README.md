# next-ai-scaffolding

Not a runnable app — a recipe for an AI coding agent.

`INSTRUCTIONS.md` walks the agent through scaffolding a new web app from
scratch: Next.js (App Router), TypeScript, Tailwind CSS, tRPC, Drizzle ORM
with PostgreSQL, Clerk for auth, and Docker for packaging. Point an agent at
this repo and have it follow `INSTRUCTIONS.md` step by step.
